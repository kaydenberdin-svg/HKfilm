HKFilm — yayın öncesi demo
1) index.html dosyasını açarak katalog demosunu görüntüleyin.
2) admin.html sayfasında demo şifresi: HKfilm2026!
3) Bu sürüm statik katalog demosudur. Gerçek kullanıcı üyeliği, kalıcı yönetici paneli ve video barındırma henüz bağlı değildir.
4) Yayınlamak için klasörü GitHub deposuna yükleyip Vercel'de New Project > Import Git Repository > Deploy adımlarını izleyin.
5) Herkese açık gerçek yayına geçmeden önce yönetici şifresini istemci kodundan kaldırıp Supabase Auth/RLS ile sunucu tarafında doğrulama kurun.
6) Kataloğa eklenen film isimleri/bilgileri listeleme amaçlıdır; video bağlantıları boş bırakılmıştır. Yalnızca yayın hakkına sahip olduğunuz kaynakları ekleyin.
